# Markdown

Format persistent agent-authored Markdown files according to repository conventions. When no
formatter or applicable convention covers a persistent local artifact, wrap its prose at 100
columns. This rule does not apply to conversational responses.

For manually wrapped artifacts, do not reflow unrelated existing content solely to satisfy wrapping.
Fenced code blocks and tables follow the formatting of their contents. Prefer rewording before
exceeding the limit. Do not split exact technical text, URLs, file paths, inline code spans, or
semantically significant line breaks.
