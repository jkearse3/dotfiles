# Investigate

Answer the controlling question using read-only evidence. Investigation does not
authorize implementation of its findings.

1. Infer the question, material scope, exclusions, and decisive evidence from
   the user's request and available context. Ask only if the question is absent
   or materially ambiguous.
2. Gather the lowest-cost authoritative evidence. Keep dependent checks ordered
   and run independent checks concurrently when useful.
3. Reconcile conflicts and distinguish observations from inferences. Pursue only
   gaps that could change the conclusion or next action.
4. Re-check decisive claims and source locations.

Lead with the answer, followed by material findings and precise sources. Report
only uncertainty or evidence limits that affect the conclusion or next action.
Synthesize rather than returning raw notes, a chronology, or a plan. Do not
execute recommendations.
